Accounts and orgs

  • Developer Edition org #1 — will become your Dev Hub. Sign up. Use a plus-addressed email you control (you+devhub@example.com).
  • Developer Edition org #2 — will own your namespace. Keep it empty.
  • Trailhead account (same email is fine) — useful for the ISV trails and for Trailhead Playgrounds as extra throwaway orgs.
  • Partner Community access — only if your company is a Salesforce partner. Ask your alliances/ISV ops team for access to partners.salesforce.com rather than signing up yourself.
  • Partner Business Org access — needed for Security Review (Part 13) and AppExchange listing (Part 15). Not needed to complete packaging, installs, or CI with free DE orgs.

B · Local development prerequisites

Install

[[code bash]] # --- Core --------------------------------------------------------------- brew install git node # Node Active LTS (22 or 24) npm install --global @salesforce/cli # --- Verify ------------------------------------------------------------- git --version # >= 2.30 node --version # v22.x or v24.x sf --version # @salesforce/cli/2.x sf package --help # packaging is often JIT; this is the real check # --- Optional but used later in this course ---------------------------- npm install --global @salesforce/plugin-packaging # only if `sf package --help` fails sf plugins install code-analyzer # Part 13 security scanning npm install --global prettier prettier-plugin-apex # formatting # --- VS Code ------------------------------------------------------------ code --install-extension salesforce.salesforcedx-vscode [[/code]]

The one setup mistake that costs beginners a day: having both sfdx (v7) and sf (v2) installed. Symptoms: an org authenticates but a later command says it is unknown; sf org list and sfdx force:org:list disagree. Fix: npm uninstall --global sfdx-cli (npm installs only; also remove any old OS installer) and re-run sf org login web.

Java

Not required for the CLI. Required for some static-analysis tooling (PMD / Graph Engine inside Salesforce Code Analyzer). If you hit a Java error in Part 13: brew install --cask temurin@17 and set JAVA_HOME. Verify the Java version required by the Code Analyzer release you install.

Git & GitHub

  • GitHub account with SSH key configured (ssh -T git@github.com succeeds)
  • You can create a private repo and push to it
  • You understand: branch, commit, merge, rebase (basic), tag, pull request
  • Your Git identity is set: git config --global user.name / user.email
