Every command you need, grouped by job. Format: command → purpose → which org → what you get back. Written for sf CLI v2 — run sf <topic> --help if a flag differs in your version.

Flag shorthands used throughout: -o = --target-org, -v = --target-dev-hub, -a = --alias, -p = --package, -d = --duration-days (scratch orgs) or --source-dir (deploy — yes, that is confusing; prefer long flags in scripts).
